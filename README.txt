Yume

Запуск
1. Установить Python 3.10+.
2. Выполнить: pip install -r requirements.txt
3. Если есть старые аккаунты, сначала запустить: python migrate_users.py
4. Запустить: python app.py
5. Открыть http://127.0.0.1:5252

Миграция
Перед переносом остановите приложение и сделайте резервную копию data/users.json и data/moods.json. Скрипт перенесёт аккаунты в SQLite и хеширует пароли. После проверки входа и истории настроения уберите исходные JSON-файлы из проекта и из Git. Не публикуйте их.

База: data/yume.db. Для другого пути задайте YUME_DATABASE_PATH.
Секрет сессии автоматически создаётся в data/.secret_key. Для сервера задайте YUME_SECRET_KEY в переменных окружения. При HTTPS установите YUME_HTTPS=1.

Для Render и других хостингов используйте постоянный диск для базы SQLite либо настройте PostgreSQL.
